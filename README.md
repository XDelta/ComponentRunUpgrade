# ComponentRunUpgrade

A [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader) mod for [Resonite](https://resonite.com/) that adds an option to re-run some components' cleanup or upgrade methods.


A 'Run Upgrade' button will be added to the following components and any subtypes of them:
RadiantDashScreen
- DesktopScreen
- ExitScreen
- GridContainerScreen
- LegacyRadiantScreenWrapper


Requires [CustomUILib](https://github.com/art0007i/CustomUILib)

Related to testing cleanup for https://github.com/Yellow-Dog-Man/Resonite-Issues/issues/594

Mod requested by Prime here https://discord.com/channels/901126079857692714/1542746876091174962/1542746876091174962

## Installation
1. Install [ResoniteModLoader](https://github.com/resonite-modding-group/ResoniteModLoader).
1. Install [CustomUILib](https://github.com/art0007i/CustomUILib) into your mods folder.
1. Place [ComponentRunUpgrade.dll](https://github.com/XDelta/ComponentRunUpgrade/releases/latest/download/ComponentRunUpgrade.dll) into your `rml_mods` folder. This folder should be at `C:\Program Files (x86)\Steam\steamapps\common\Resonite\rml_mods` for a default install. You can create it if it's missing, or if you launch the game once with ResoniteModLoader installed it will create this folder for you.
1. Start the game. If you want to verify that the mod is working you can check your Resonite logs.
